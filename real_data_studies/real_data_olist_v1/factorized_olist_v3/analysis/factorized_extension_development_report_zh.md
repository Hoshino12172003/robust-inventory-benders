# Olist 因子化不确定性扩展：开发实验报告

## 1. 设计

本扩展使用训练期周需求的正向标准化残差提取6个共同冲击因子。每个区域—产品单元按最大绝对载荷分配至一个因子，前6个因子解释约80.50%的训练残差能量。为避免单向上偏不确定集退化为“所有因子同时激活”，预算固定为3，因此共有42个因子场景。测试集未参与因子估计、参数选择或算法比较。

真实网络采用20和30个卖家城市、5类产品和8个需求区域。每个完整场景分别包含800和1200个运输追索变量。所有场景均通过穷举固定场景 LP 进行最终认证，并用包含全部42个场景的确定性等价模型核对目标值。

## 2. 成本余量选择

rho=0.01 时直接模型的公平目标为0，属于退化公平问题。rho=0 时直接模型不可行，因为成本锚点仅在1e-4相对间隙内认证，不能作为严格零余量预算。

在算法运行前使用直接模型扫描小余量，并按“最小的可行且目标严格大于0的余量”规则冻结 rho=0.0001。20城市直接模型参考目标为 T=0.01197036916。

## 3. 有效比较结果

| 规模 | 方法 | 状态 | 时间（秒） | 迭代 | T | 与直接模型一致 |
|---|---|---:|---:|---:|---:|---:|
| 20城市 | Hybrid（晋升阈值2） | optimal | 6.696 | 3 | 0.01197036916 | 是 |
| 20城市 | 纯 CCG | optimal | 6.390 | 5 | 0.01197036916 | 是 |
| 30城市 | Hybrid（晋升阈值2） | optimal | 14.303 | 3 | 0.02720027583 | 是 |
| 30城市 | 纯 CCG | optimal | 8.929 | 5 | 0.02720027583 | 是 |

20城市中 Hybrid 慢约4.8%；30城市中 Hybrid 慢约60.2%。扩大完整追索块没有形成稳定性能交叉。

## 4. 作废或失败的诊断

- rho=0.01 下 Hybrid 曾比纯 CCG 快约2.11倍，但两者目标均为0。该结果只反映退化可行性问题，不应作为公平算法优势证据。
- rho=0 下两种分解最初返回不同目标，而直接模型证明该预算不可行，因此相关结果全部作废。
- 将场景晋升门槛提高至999的 cut-dominant 版本运行65.637秒、48轮、227条割后以 `uncertified_infeasible` 结束，未取得认证。

## 5. 结论

因子化真实数据消除了成本锚点瓶颈，但仍未提供可辩护的 Hybrid 优于纯 CCG证据。在非退化且由直接模型核验的20和30城市问题上，Hybrid均更慢。当前实现的主要问题是：多割和场景晋升减少了外层迭代，却增加了主问题负担；完全取消场景晋升又导致弱割累积和认证失败。

因此，不能通过继续选择 rho、城市数或需求因子来制造优势。若论文必须提出 Hybrid 相对纯 CCG 的普遍速度优势，需要重新设计更强的投影割或回调式 branch-and-Benders-cut，并重新运行算法性能实验。否则应将贡献限定为相对显式确定性等价模型的可扩展性和完整认证能力。
