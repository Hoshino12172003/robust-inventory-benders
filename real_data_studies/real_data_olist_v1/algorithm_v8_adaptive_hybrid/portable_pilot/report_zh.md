# Hybrid v8 可移植性 pilot 结果

本实验严格按照 `docs/hybrid_v8_portable_pilot_protocol.md` 执行。协议、运行脚本、配置、候选源码哈希以及3个实例和场景文件均在任何优化运行前提交至PR #72的提交`6ffa4a5`。运行后未修改候选算法、输入、种子、门槛或方法顺序。

| Seed | Hybrid v8（秒） | 纯CCG（秒） | Batch-4（秒） | v8割数 | v8与Direct误差 |
|---:|---:|---:|---:|---:|---:|
| 0 | 0.355 | 0.407 | 0.358 | 0 | 4.44×10^-15 |
| 1 | 0.370 | 0.487 | 0.363 | 0 | 0 |
| 2 | 0.309 | 0.445 | 0.295 | 0 | 2.22×10^-16 |

Hybrid v8、纯单场景CCG和Batch-4均为3/3认证。Hybrid v8相对纯CCG为3胜0负，几何平均加速比为1.295；相对Batch-4为1胜2负，几何平均速度比为0.982。Hybrid v8与完整Direct模型的最大目标绝对误差为4.44×10^-15。

三组实例均未达到Farkas割效力门槛，因此没有提交割。该结果证明冻结的v8实现能够移植到仓库生成的非Olist实例并保持精确目标和完整认证，也再次表明相对单场景纯CCG的速度优势主要来自有界批量场景块。由于本实验只有3个公开开发种子，不能作为独立论文holdout，也不能证明割模块具有增量加速作用。
