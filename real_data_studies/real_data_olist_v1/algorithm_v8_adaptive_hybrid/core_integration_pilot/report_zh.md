# Hybrid v8 核心接入开发试验报告

本试验严格按照提交 `bf9b34f` 中预先冻结的协议运行，使用此前未用于该
试验的开发种子 10、11 和 12。试验不属于正式留出验证，也不替换论文中已经
冻结的任何实验结果。

三组实例中，核心 v8 与旧版核心 Hybrid 均为 3/3 完成精确认证。v8 相对
79 场景 Direct 模型的最大目标值绝对误差为 `2.44e-15`，说明核心接入没有
改变被求解的鲁棒公平模型。运行时间上，v8 在三组中取得 2 胜 1 负，旧版
Hybrid 相对 v8 的几何平均时间比为 `1.129`，即本开发样本中 v8 的几何平均
加速约为 12.9%。

该结果的解释边界很重要：三组 v8 运行均未触发归一化 Farkas 割，因此本轮
验证的是多场景块路径、精确最终分离和核心实现的正确性，不能据此声称割分支
优于 Batch-4 CCG，也不能外推为正式性能结论。后续若要证明完整 Hybrid 机制
的增量作用，必须在新的预登记协议中报告割被实际触发的实例，并进行场景块与
割分支的消融；不能在看到正式留出结果后挑选数据。

原始逐种子输出、汇总及其 SHA-256 均保存在本目录。输入哈希位于
`input_freeze.json`，结果哈希位于 `result_manifest.json`。
